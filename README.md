# Find Your Adventure — Integrated Frontend + RAG/Groq Operator AI

This project preserves the existing React/Vite five-question adventure quiz and deterministic matching engine, while adding an optional natural-language operator recommendation capability.

## What was added

- Real semantic RAG over `src/data/operators.json`.
- Persistent vector index generated by `npm run rag:index`.
- Local `sentence-transformers/all-MiniLM-L6-v2` embeddings using Transformers.js; no hosted Hugging Face inference API is used.
- Groq API for intent understanding and grounded response generation.
- Backend-only Groq API key handling.
- Hybrid retrieval: semantic similarity + structured activity/location constraints.
- Response validation against retrieved operator IDs and source metadata.
- Basic current-session follow-up context such as "Which of those are in Uttarakhand?"
- Minimal AI UI added to the existing intro experience; the original quiz, matcher, cards, styling and result flow remain intact.

## Requirements

- Node.js 20+
- A Groq API key
- Internet access only on first model download (the model is cached locally afterward)

## Installation

```bash
npm install
```

Create `.env` from `.env.example`:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=your_supported_groq_model
EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2
RAG_TOP_K=15
RAG_MAX_RESULTS=5
PORT=3001
```

The Groq key is used only by the backend. Never use `VITE_GROQ_API_KEY`.

Embeddings run locally with `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions). Transformers.js downloads the model files from the model hub on first use and caches them locally; embedding generation itself does not call the hosted Hugging Face Inference API and no Hugging Face API token is required.

## Build the RAG knowledge base

```bash
npm run rag:index
```

This reads `src/data/operators.json`, normalizes each operator into a factual document, generates embeddings, and writes the persistent index to `rag/operator-index.json`. It is safe to rerun after the operator dataset changes.

## Run

Use two terminals:

Terminal 1:

```bash
npm run server
```

Terminal 2:

```bash
npm run dev
```

Or, if `concurrently` is installed:

```bash
npm run dev:all
```

The frontend is normally at `http://localhost:5173` and the backend at `http://localhost:3001`.

Health check:

```text
GET /api/health
```

## RAG request

```http
POST /api/rag/ask
Content-Type: application/json
```

```json
{
  "question": "Which operators provide trekking in Uttarakhand?",
  "context": {
    "operatorIds": [],
    "previousQuestion": ""
  }
}
```

## Grounding and safety

The operator dataset is authoritative. The AI is not allowed to invent operators, IDs, ratings, locations, services, prices, availability, or reviews. Missing fields are treated as unknown rather than negative evidence.

The final model output is validated so only IDs from the retrieved candidate set can reach the frontend, and factual metadata is copied from the source operator records.

## Original quiz

The existing quiz still produces:

```js
{ q1, q2, q3, q4, q5 }
```

and continues to call:

```js
getRecommendation(answers, operators, matchingRules)
```

No Groq call is used by the original deterministic quiz matcher.
